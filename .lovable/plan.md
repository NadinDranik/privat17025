Перенос списка чатов в левый сайдбар

Сейчас список чатов отображается в основной области страницы (`chats.index.tsx` карточками), а левая панель содержит только 2 ссылки: «Чаты» и «Админ-панель». Нужно перенести список чатов непосредственно в сайдбар, чтобы он был всегда виден и работал как навигация.

Изменения:
1. Обновить сайдбар в `_authenticated.tsx`:
   - Загружать список чатов из таблицы `chats` (сортировка по `order_index`, затем `created_at`).
   - Отображать каждый чат отдельной строкой: бейдж с номером пункта ГОСТ + краткое название.
   - Подсвечивать активный чат (по `chatId` из параметров маршрута).
   - Клик по чату → навигация на `/chats/$chatId`.
   - Добавить ссылку «← Все чаты» или похожую, ведущую на `/chats`.
   - Оставить «Админ-панель» без изменений.

2. Обновить `chats.index.tsx`:
   - Убрать список карточек чатов.
   - Показывать приветственный экран с текстом «Выберите чат из списка слева, чтобы начать обсуждение».
   - Оставить заголовок «Чаты» и баннер подписки (если пользователь не подписчик).
   - При наличии чатов и при первом входе — редиректить на первый доступный чат.

3. Оставить `chats.$chatId.tsx` без изменений — он и так рендерит переписку в основной области.

Результат:
- Левая панель всегда показывает актуальный список чатов.
- Основная область показывает либо приветственный экран (`/chats`), либо конкретную переписку (`/chats/:chatId`).
- Работает подписка и админ-панель как раньше.
