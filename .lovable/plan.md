
# План: сайт с чатами по ГОСТ ISO/IEC 17025-2019

## Что строим
Веб-площадка в формате тематических чатов по пунктам ГОСТ 17025-2019. Вы (админ) создаёте чаты, ведёте экспертные обсуждения. Подписчики (после оплаты подписки) могут читать, писать сообщения, прикреплять фото/видео/документы.

## Стек и инфраструктура
- TanStack Start (React) — фронтенд и серверные функции
- Lovable Cloud — БД (Postgres), авторизация, хранилище файлов, realtime
- Оплату подключаем вторым шагом (как договорились) — сейчас закладываем поле `is_subscribed` у пользователя и «заглушку» страницы подписки

## Структура страниц
- `/` — лендинг: о проекте, о ГОСТ 17025, призыв подписаться, вход/регистрация
- `/auth` — вход/регистрация (email+пароль, Google)
- `/chats` — список всех чатов (пунктов стандарта), бейджи новых сообщений
- `/chats/$chatId` — окно чата: история сообщений, композер, загрузка вложений
- `/subscribe` — страница подписки (пока заглушка с описанием тарифа)
- `/admin` — админ-панель: создать/переименовать/удалить чат, модерация сообщений, список подписчиков

Доступ:
- Неавторизованным: только `/`, `/auth`, `/subscribe`
- Авторизованным без подписки: те же + превью списка чатов с CTA «оформить подписку»
- Подписчикам: чтение и запись во всех чатах
- Админу (вам): всё + админ-панель

## Модель данных (Lovable Cloud)
- `profiles` — id (FK auth.users), display_name, avatar_url, is_subscribed, subscription_until
- `user_roles` — user_id, role ('admin' | 'subscriber') — отдельная таблица, проверка через security-definer функцию `has_role`
- `chats` — id, gost_clause (напр. «7.2»), title, description, order_index, created_at
- `messages` — id, chat_id, author_id, body (text), created_at, edited_at, deleted_at
- `message_attachments` — id, message_id, storage_path, mime_type, size, kind ('image'|'video'|'file')
- Storage bucket `chat-attachments` (приватный, доступ через signed URLs подписчикам)

RLS:
- Читать `chats` — все авторизованные
- Читать `messages` — только подписчики и админ
- Писать `messages` — подписчики и админ
- Управлять `chats` — только админ
- Storage: загрузка/чтение только для подписчиков и админа

## Чаты по ГОСТ
Создаёте сами через админ-панель (как выбрали). Я добавлю удобный визард: ввести номер пункта + название + описание, задать порядок в списке. Первого админа назначаем вашему аккаунту вручную после регистрации (через SQL — я опишу шаг).

## Сообщения и вложения
- Композер: textarea + кнопка прикрепления (изображения, видео, pdf/doc/xlsx/txt)
- Превью изображений и видео прямо в ленте, файлы — карточкой со скачиванием
- Realtime-обновление ленты через Lovable Cloud realtime
- Поддержка markdown в тексте (жирный/код/ссылки)
- Админ может удалять любое сообщение, автор — своё

## Подписка (заглушка под платежи)
- Страница `/subscribe` с описанием тарифа и кнопкой «Оплатить» (пока выводит сообщение «Скоро»)
- Поле `is_subscribed` + `subscription_until` в `profiles` управляются админом из админ-панели — это даст возможность вручную выдать доступ на время теста
- На втором шаге (когда выберете провайдера) подключим: Stripe/Paddle (международные карты) либо Telegram-бот с ЮKassa/CloudPayments для РФ. Архитектура уже готова — добавится только серверная функция оформления подписки и вебхук активации.

## Дизайн
Чистый деловой стиль (тема — стандартизация и метрология): спокойная палитра (тёмно-синий/графит + белый, акцент — янтарный), типографика с серифным заголовком и гротеском в тексте, плотная читаемая лента сообщений как в Telegram/Slack. Светлая и тёмная темы.

## Технические детали
- Server functions (`createServerFn`) для всех мутаций (создание чата/сообщения, выдача подписки)
- Загрузка файлов: подписанные URL Lovable Cloud Storage, лимит 20 МБ на файл
- Валидация форм через zod
- Защищённые маршруты через `_authenticated` layout
- SEO: отдельные `head()` на лендинге, `/subscribe`, странице чата (название пункта ГОСТ)

## Порядок реализации
1. Включить Lovable Cloud, создать схему БД (profiles, roles, chats, messages, attachments), RLS, bucket
2. Авторизация (email+пароль и Google), страница `/auth`, триггер создания профиля
3. Лендинг `/` + страница `/subscribe` (заглушка)
4. Список чатов и страница чата с realtime-лентой и композером без вложений
5. Загрузка и отображение вложений (изображения/видео/файлы)
6. Админ-панель: CRUD чатов, выдача подписки, модерация сообщений
7. Полировка дизайна, тёмная тема, мобильная адаптация
8. (Отдельный шаг по вашему сигналу) Подключение платёжного провайдера
